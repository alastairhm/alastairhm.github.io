Counting up to 1023

Decided in the end to wire up all 10 LEDS in the LED bar graph.
Using the sketch below get the results shown in the video.



int numLed = 10;
int ledpins[] = {
  13,12,11,10,9,8,7,6,5,4};
int mask[] = {
  1,2,4,8,16,32,64,128,256,512};
int counter = 0;

void setup() {             

  // initialize the digital pin as an output.
  for (int i=0;i<numLed;i++){
    pinMode(ledpins[i], OUTPUT);
    digitalWrite(ledpins[i], HIGH);
    delay(250);
  }
}

Arduino Binary second counter

Next step with my Arduino is to set up a binary second counter.
Basic using the LED Bar Graph or six single LEDs to count seconds in binary




/*
Binary Second Counter
 
 Created Alastair Montgomery 22/11/2012
 
 */

int ledPins[] = {
  7,8,9,10,11,12};
int mask[] = {
  1,2,4,8,16,32};
int ledCount = 6;


void setup() {
  for (int thisPin =0; thisPin < ledCount; thisPin++) {
    pinMode(ledPins[thisPin], OUTPUT);
  }
}
